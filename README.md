# Odimibo Web - Allmiibo Manager & Nintendo Switch 1 & 2 Hub

เว็บแอปพลิเคชันจำลองและจัดการ Allmiibo / Pixl.js รองรับทั้งเครื่องจำลอง (Virtual Device) และเชื่อมต่อผ่าน Web Bluetooth (BLE) พร้อมคลังข้อมูล Amiibo ครบ 900+ ตัวละคร สำหรับใช้งานกับ Nintendo Switch 1 และ Nintendo Switch 2

## ฟีเจอร์เด่น
- 🎮 จำลองหน้าจอ OLED เรโทร 128x64 พร้อมปุ่มสัมผัสและระบบสั่น
- 📚 คลัง Amiibo ครบ 932 ตัวละครจาก GitHub (Zelda BotW / TotK, Mario, Smash Bros, Splatoon, Pokemon, ฯลฯ)
- 🎲 ระบบสุ่ม UID ใหม่ เพื่อแตะสแกนรับของในเกม Switch ซ้ำได้ไม่จำกัด (Unlimited Drops)
- 💾 สร้างไฟล์ .bin มาตรฐาน NTAG215 (540 ไบต์) พร้อมคำนวณค่า Checksum ถูกต้อง
- 🔗 รองรับ Web Bluetooth (BLE) กับเครื่อง Allmiibo จริง (Nordic UART Service)
